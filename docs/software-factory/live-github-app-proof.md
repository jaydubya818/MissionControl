# Governed GitHub App Proof

The approved delivery path is:

`Mission → Plan → WorkOrder → Task → Attempt → commit → pull request`

This path preserves human-approved intent through bounded execution. The Mission defines the outcome, the Plan records the approved approach, and the WorkOrder scopes delivery. A Task defines the authorized change, while an Attempt records the execution and its evidence. The resulting commit provides an immutable repository record, and the pull request is the governed review and approval boundary before any merge.
