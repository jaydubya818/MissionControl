# Status & Migration Archive

Point-in-time status reports, QC summaries, and migration planning documents,
moved here from the repository root to keep the top level focused on the
living docs (`README.md`, `AGENTS.md`, `CLAUDE.md`, `SKILL.md`, `docs/`).

These files are historical records: they describe the state of the system at
the time they were written and are not kept up to date. For current
architecture and status, see `docs/software-factory/` and `docs/product/`.
