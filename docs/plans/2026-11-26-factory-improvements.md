## Design and throughput

Three isolated worktrees own authorization, intake, and replay changes. Root owns
readiness diagnostics, review projection, integration, and the final report.
Each specialist first grounds the current subsystem and compares a direct
extension with a new coordinator. Prefer direct extension when it preserves the
existing source of authority and eliminates a second state machine.

Shared schema changes are reconciled by root. No writer changes another's
worktree, deploys, creates external webhooks, or weakens runtime admission.
Independent reviewers receive the exact proposed source and retained results.

The primary data shapes are authenticated scoped commands, idempotent source
deliveries, frozen replay manifests with attributable per-case receipts, and
advisory review facets projected from canonical evidence. New state must have a
restart/retry interpretation. Public entry points validate external input and
derive scope from the persisted source of authority.

## Completion predicates

behavioral negative controls, compatible typechecks, retained regression results,

repairs cannot satisfy this predicate.
