# Factory UI Roadmap — Sequenced Implementation Plan

> **For Claude:** Use GSD `/gsd:execute-phase` per track, or Superpowers `executing-plans` task-by-task. Do not edit this file during implementation — log progress in `progress.txt`.

**Goal:** Move Mission Control from “agent activity wallpaper” to a software-factory operator surface: exceptions first, evidence traceable, v2 design complete on shipped pages, analytics with drill-down, and no fake placeholders.

**North-star questions every shipped page must answer:**

1. What needs my attention right now?
2. What proves this work is done?
3. What is the next action I can take in one click?

**Architecture:** Four tracks executed in overlapping sprints. Track 1 (product focus) is highest leverage. Track 2 (de-slop + layout) runs in parallel on every page touched. Track 3 extends the existing dashboard plan. Track 4 removes trust-breaking stubs.

**Tech stack:** React 18, TypeScript, Convex, Tailwind v4, shadcn/ui, Recharts (`chartTheme.ts` — not NeonChartTheme). Demo UI: `sf-96-eos-demo` worktree on `:5199`; main repo on `:5180`.

## Track 1 — Product focus (exceptions + evidence)

### Phase 1.1: Exception-first Overview (Sprint 1)

**Problem:** Overview shows six KPI tiles before “Needs attention.” Operators scroll past wallpaper to find work.

**Files:**

- Modify: `apps/mission-control-ui/src/DashboardOverview.tsx`
- Modify: `apps/mission-control-ui/src/sections/HomeSection.tsx` (if wrapper exists)

**Steps:**

2. Deduplicate attention items (merge identical approval rows; group by task/work order).
3. Add one-click actions per row: Approve, Open task, Unblock, View run (wire to existing modals/navigation).

**Acceptance:**

- First visible content below header is actionable attention queue (not KPI grid).
- Every attention row has ≥1 working action.

### Phase 2.2: Layout contract (ongoing)

**Problem:** Pages without flex height chain collapse at wide viewports (Tasks bug root cause: Fragment layout in `sf-96-eos-demo`).

**Contract (all board/canvas views):**

```tsx
// Page root inside AppShellV2
<div className="flex h-full min-h-0 w-full flex-1 overflow-hidden">
  {/* optional sidebars */}
  <main className="flex min-h-0 min-w-0 flex-1 flex-col overflow-hidden">
    <PageHeader … />           {/* shrink-0 */}
    <PageToolbar … />           {/* shrink-0, overflow-x-auto flex-nowrap */}
    <div className="flex min-h-0 flex-1 flex-col overflow-hidden">
      {/* primary content flex-1 */}
    </div>
  </main>
</div>
```

**Files:**

- Enforce: `apps/mission-control-ui/src/components/PageShell.tsx` (use everywhere)
- Audit: all `sections/*Section.tsx` views

**Acceptance:** No Ops-style Fragment layouts returning sibling block elements to AppShellV2. CDP audit: primary content `top` ≤ 80px at 1920×1080.
