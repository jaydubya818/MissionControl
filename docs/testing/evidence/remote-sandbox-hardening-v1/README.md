# Remote Sandbox Hardening V1

## Decision

**HOLD**

The existing `SandboxProvider` + exe.dev path gained independently useful fail-closed controls, but the current provider/image combination does not satisfy the requested production-pilot security gate.

Two blockers are decisive:

1. exe.dev accepts an OCI image but exposes no control-plane egress/firewall option. The candidate can constrain the non-root executor with guest `nftables`, but root in the guest remains the policy administrator. That is defense in depth, not provider-enforced egress isolation.
2. The smallest functional candidate image still has seven unresolved High findings in the current Grype database. The image publication workflow therefore stops before push, digest attestation, or certification.

Because those gates failed before publication, no candidate image was promoted, no production-routable profile was created, and the live three-workload gate was intentionally not run. The last provider inventory check was zero.

## What passed

- An exact linux/amd64 base digest, Node `v26.7.0`, Codex CLI `0.146.0`, package integrities, native Codex digest, non-root UID/GID, and required tools are frozen in the candidate build inputs.
- Attempt startup contains no `npx` or npm installation. The runtime has no npm/npx executable.
- Startup compares expected and provider-reported image identity, Node/Codex identity, the native Codex SHA-256, and the frozen toolchain-input SHA-256 before the executor starts.
- The executor runs as UID/GID 10001 with `no_new_privs`, a fixed home/tmp, a dedicated repository, and no GitHub, provider-admin, OpenRouter-management, Mission Control service, publication, verification, or acceptance credential.
- Two fresh sequential local linux/amd64 containers proved OpenRouter reachable while a previously reachable external control endpoint, private network, metadata address, and unexpected DNS were blocked for the execution UID. Protected filesystem paths were read-only and the second container could not observe the first container's sentinel.
- Cancellation now terminates the executor process group and writes a typed `CANCELED` result. stdout/stderr capture is memory-bounded, hashed, byte-counted, redacted before tail truncation, and retained in terminal diagnostics.
- The candidate is explicitly `qualificationOnly`, visibly `DEGRADED`, and excluded from production routing.

## Scope and authority

No second sandbox architecture, worker, lease model, recovery path, verifier, acceptance mutation, publication permit, merge path, or Guarded Auto path was added. `workOrders.accept` remains canonical acceptance; human merge remains separate; Remote Sandbox retains no acceptance or publication authority.
