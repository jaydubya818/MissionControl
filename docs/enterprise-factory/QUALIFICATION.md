## Three-tier routing matrix

| Fixture | Expected recommendation | Required negative variant |
| --- | --- | --- |
| Summarize document / spreadsheet analysis / Python utility | SOFIE_NATIVE_DIRECT | Harness unqualified, environment disabled, effects prohibited |
| Five competitors / market report / qualified small code review | SOFIE_NATIVE_MULTI_AGENT | Unqualified Skill, tampered Role, parent budget exhausted, cross-owner context |
| CRM / application feature | MYFACTORY | Repository authority missing, FactoryVersion stale, no verifier |
| Agentic HR / coordinated repository program | MISSIONCONTROL_NATIVE | No planning approval; proposal remains non-executable |
| Enterprise HR using multiple factories | MISSIONCONTROL_HYBRID | Delegation revoked, partner unavailable, downstream evidence stale |
| Ordinary question | CHAT_ONLY | Must create no execution authority |

Agent count and repository count alone never select a tier. If the preferred route is unavailable, deny or propose a separately authorized alternative. After admission, stop/reconcile before reassignment. UNKNOWN forbids automatic retry or fallback.
