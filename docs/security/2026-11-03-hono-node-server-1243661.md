# Advisory 1243661 (`@hono/node-server`) — remediation check

Date: 2026-11-03

Disposition: **contained 1.x pin to 1.19.18 for GHSA-jpvv-r467-5p4w**. Keep the
existing moderate **1243661** acceptance in
`docs/security/dependency-risk-acceptances.json` (review by 2026-11-16, expires
2026-12-15). 1243661 still has no 1.x patch.

## Finding

GHSA-rmxm-3fg6-px4f / advisory 1243661: `serveStatic` double-decodes the
request path. Affected range remains `>= 1.19.10, < 2.1.3`. First patched
release is **2.1.3**.

GHSA-jpvv-r467-5p4w: raw backslash in the request path is treated as `/`.
That path runs through `serve()`, which `apps/orchestration-server` uses.
**1.19.18** patches it and keeps `engines.node` at `>=18.14.1`.

## Options checked

| Option | Result |
| --- | --- |
| Same-major 1.x for 1243661 | **None.** 1.19.18 does not change the GHSA-rmxm patched-version set. `pnpm audit` still reports 1243661. |
| Same-major 1.x for GHSA-jpvv | **1.19.18.** Contained pin; Node 18 floor preserved. |
| Scoped override onto 2.1.3+ | 2.1.3+ `engines.node` is `>=20`. Repository floor is `>=18.0.0`. That is a Node-floor change, not a contained override. |
| Raise Node floor to 20 | Touches `engines`, CI images, Vercel, and every package that currently assumes Node 18. Out of this follow-up's release scope. |
| Exploitability of 1243661 | `serveStatic` is unused. `apps/orchestration-server` imports only `serve` from `@hono/node-server`. Core `hono` is already on 4.13.11 for the related serveStatic advisory 1242595. |

## Decision

Pin `@hono/node-server` at **1.19.18** for the `serve()` backslash fix. Leave
the recorded 1243661 acceptance in place until a 1.x release is listed as
patched for GHSA-rmxm-3fg6-px4f, or until the repository Node floor moves to
20 and 2.1.3+ can be taken as a dedicated change.
