# Advisory 1243661 (`@hono/node-server`) — remediation check

Date: 2026-11-03

Disposition: **no contained remediation**. Keep the existing moderate
acceptance in `docs/security/dependency-risk-acceptances.json` unchanged
(review by 2026-11-16, expires 2026-12-15).

## Finding

GHSA-rmxm-3fg6-px4f / advisory 1243661: `serveStatic` double-decodes the
request path. Affected range remains `>= 1.19.10, < 2.1.3`. First patched
release is **2.1.3**.

## Options checked

| Option | Result |
| --- | --- |
| Same-major patched 1.x | **None for this advisory.** Latest 1.x is 1.19.18 (2026-11-02). That release rejects raw backslash paths (paired with 2.1.6) and does **not** change the GHSA patched-version set. `pnpm audit` would still report 1243661 on 1.19.18. |
| Scoped override onto 2.1.3+ | 2.1.3+ `engines.node` is `>=20`. Repository floor is `>=18.0.0`. That is a Node-floor change, not a contained override. |
| Raise Node floor to 20 | Touches `engines`, CI images, Vercel, and every package that currently assumes Node 18. Out of this follow-up's release scope. |
| Exploitability in this repo | `serveStatic` is unused. `apps/orchestration-server` imports only `serve` from `@hono/node-server`. Core `hono` is already on 4.13.11 for the related serveStatic advisory 1242595. |

## Decision

Leave `@hono/node-server` pinned at 1.19.17 and leave the recorded
acceptance in place. Revisit when a 1.x release is listed as patched, or when
the repository Node floor moves to 20 and 2.1.3+ can be taken as a dedicated
change.
